# 段译 · Edge 网页 AI 双语翻译

段译用你自己的 API Key 翻译网页正文、选区和悬停段落。扩展无需注册或购买会员，模型调用按你所选服务商的规则结算。默认目标语言为简体中文。

## 安装和配置

1. 在 GitHub 仓库点击 **Code → Download ZIP**，把文件解压到一个长期保留的目录。
2. 在 Edge 打开 `edge://extensions`，开启「开发人员模式」，点击「加载解压缩的扩展」，选择含有 `manifest.json` 的文件夹。可在「扩展」菜单里将「段译」固定到工具栏。
3. 打开一个普通网页，点击段译图标 →「配置 API Key」。选择服务商，填写自己的 Key 并核对模型名。可选 OpenAI、DeepSeek、硅基流动、Google Gemini、Anthropic Claude，或自定义 OpenAI 兼容接口。
4. 点击「测试连接」，在 Edge 的权限提示中核对 API 域名。测试会实际提交一句英文并显示译文。这次调用计入服务商用量。点击「保存设置」后，打开外文网页即可使用。

OpenAI 兼容地址填服务商公布的 HTTPS 基础地址，保留其要求的路径，例如 `https://api.openai.com/v1` 或 `https://api.deepseek.com`。模型名称必须是该账号可调用的模型 ID。Gemini 和 Claude 预设直接使用官方原生接口。如果 Claude 服务商提示需要工作区，在设置中填写相应的 Workspace ID。

## 阅读操作

| 想做什么 | 操作 |
| --- | --- |
| 翻译当前页 | 点击段译图标。原文下方逐段显示译文，沿用网页字号。首屏第一段单独请求，其余段落分批并行，提前翻译视窗下方 320 像素内的内容。 |
| 快捷键翻译整页 | 在普通网页中按 **Alt+A**，直接翻译当前整页，包括导航、侧栏和页脚。再次按下会保持整页翻译。首次使用请先配置 API Key；如快捷键被另一扩展占用，到 `edge://extensions/shortcuts` 为段译的「翻译当前整页」指定组合键。 |
| 在正文与整页间切换 | 弹窗的「翻译范围」可一键选择「正文」或「整页」。正文优先识别主内容和文章，没有语义标记时回退到页面可读段落。整页还会翻译导航、侧栏和页脚。切回正文即移除这些区域的译文。新打开或刷新的页面默认用正文模式。 |
| 切换显示方式 | 在弹窗选择「双语」「仅译文」或「原文」。同页切换会复用已完成的译文。 |
| 总是翻译某个网站 | 勾选「总是翻译此网站」，允许 Edge 访问当前站点。再次打开该站时自动翻译。可从同一开关关闭。 |
| 翻译选区 | 在网页正文选中单词或句子，右键 →「翻译选中内容」。译文会显示在选区旁，按 Esc 可关闭。 |
| 只翻一个段落 | 在已经启用段译的页面，按住 Alt 悬停在段落上。想在手动站点只翻局部，也可以直接使用右键划词。 |

例如阅读电机控制资料时，同一个 `current` 可以表示“电流”或“当前”。扩展会附带标题、小节、邻近正文和本页已确认的术语，以帮助模型判断语境。代码、公式和链接通过占位符保留，译文中的链接仍可点击。

## 权限、费用与故障处理

- Key 只存放在当前 Edge 配置文件的扩展本地存储中，网页内容脚本无法读取。模型请求由扩展后台直接发往设置中选定的服务地址。更换 API 域名时须重新填写 Key。「清除本机配置」可移除已保存的 Key。
- 新网站默认由你手动触发。所选范围内的文字、标题和少量邻近文本会发送给指定服务。整页模式同样跳过表单、可编辑区域、代码块和公式。适用范围是普通 HTML 网页的主文档。
- 本机译文缓存最长复用 30 天，按网页、模型、目标语言和段落上下文区分；容量接近上限时淘汰旧项。无痕窗口只使用当前页面内存。设置页「清除译文缓存」后再刷新网页，即可重新翻译。
- 翻译请求按自然段组织。单段直接取译文，多段使用带编号的分隔行校验对应关系，每页最多并发 3 个正文批次。DeepSeek 官方的 `deepseek-flash` 和 `deepseek-v4-pro` 翻译请求使用关闭深度思考的模式。[DeepSeek 思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)
- 提示 Key 无效时检查 Key 和对应平台；提示模型不存在时核对模型 ID；提示限流或余额不足时检查服务商控制台。网络中断时服务商可能已经处理了请求。队列会暂停，保留已经完成的段落；确认用量后点击「手动重试」或弹窗中的「重试失败段落」。
- 改动源码后，在 `edge://extensions` 点段译卡片上的「重新加载」，再刷新需要翻译的网页。更新模型设置后，刷新原先已翻译的页面即可按新模型重新翻译。

## 验证

在 Windows PowerShell 中，进入扩展目录运行以下命令。安装和使用扩展本身无需 Node 或 Python。

```powershell
Set-Location C:\AI\edge-ai-translator
node --test tests/providers.test.mjs tests/background.test.mjs tests/cache.test.mjs
python tests/edge-smoke.py
```

第一项用模拟响应检查三种协议、密钥发送位置、段落编号、错误处理和站点权限撤销。第二项使用独立的临时 Edge 配置、一次性测试凭据和回环 HTTPS 模拟服务，依赖 Python 的 `websockets`、`cryptography` 包和本机 Edge。运行测试不需要真实模型 Key。
